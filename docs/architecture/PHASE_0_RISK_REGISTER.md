## Highest-risk release blockers

Core CRM must not begin until R-001 through R-005, R-007 through R-012, R-014 through R-021, R-023, R-030, R-033/R-034, R-038/R-044 are mitigated or covered by an approved staged-migration plan with tests. No risk is accepted merely because the static UI renders or the monorepo builds.
